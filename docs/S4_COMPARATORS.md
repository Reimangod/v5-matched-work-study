# S4 — primary comparators

Six methods share one immutable source interface and the S3 componentwise cap
enforcer: CEO* source, same-structure reoptimization, structural magnitude
pruning, V4.1 one-shot, V5 sequential without rebuilding, and full V5.

The two sequential variants differ only after an accepted child. The ablation
continues to use the original catalog snapshot; full V5 rebuilds blocks,
candidates, curvature coordinates, and resources from the child. Magnitude
pruning must physically delete generators and recount the full circuit; setting
a coefficient to zero is only an optimization control.
