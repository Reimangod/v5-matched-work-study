# MB4.1 protocol proposals v2

Status: `NO_GO_MB4_1_V2_AWAITING_INDEPENDENT_HUMAN_APPROVAL`.

This additive artifact supersedes the v1 proposal without editing it. No
protocol is approved and no execution is authorized.

The no-rebuild proposal freezes only the source structural whitelist. Each
child uses a current-runtime catalog, current numerical values, and the same
ranking and selection as full V5. Only structural candidate replenishment is
removed. Freezing source order is explicitly excluded as a compound ablation.

The magnitude proposal is a single-coordinate control. It requires a valid
registered deletion constraint, squared residual scoring (with direct
single-coordinate `theta_i^2` equivalence verified), physical generator
removal, sequential reoptimization, full circuit reconstruction and recount,
rollback, cap enforcement, and honest zero-resource reporting. Block deletion
and subset rewrites are separate protocols.

The V4.1 H2/H4 proposal generates structurally eligible candidates without
outcomes, uses canonical structural equivalence classes, chooses the lowest-ID
representative per class, and retains at most four per case in canonical order.
It uses no predictor. FCI, candidate energy, historical rank, and development
results are forbidden.

The companion human-review template contains the exact protocol digests but no
reviewer, date, decision, or checked item. An independent human must create a
new immutable review artifact; this repository must not fill those fields on
their behalf.
