# Reproducible pre-performance No-Go release

Release tag: `v5-matched-work-preperformance-no-go-v1`

S0–S2 produced valid repository-isolation, historical-correctness, and
stationary-source evidence. S3–S5 produced useful primitives and a draft
pre-outcome protocol, but the final readiness audit found that the executable
matched-work integration was incomplete. Candidate-energy evaluation count is
zero and S6–S14 were not authorized.

This release must not be described as evidence that V5 succeeds or fails under
matched work. It identifies the concrete engineering work required before a
new versioned freeze can authorize molecular execution.

No container was built and no DOI was minted. The Python constraint and
`uv.lock` are the environment freeze.
