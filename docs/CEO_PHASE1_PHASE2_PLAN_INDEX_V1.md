## 2. One-sentence research objective

Determine prospectively whether bounded joint post-growth transformations of a fixed CEO* ansatz produce an accuracy-feasible canonical CNOT frontier that cannot be explained by complete singleton transformations or a fully reoptimized earlier CEO* prefix.

## 3. Phase 1 minimum deliverables

- frozen B2 source contract and eligible source records;
- complete registered singleton universe;
- bounded registered joint universe;
- materialized-circuit and canonical-resource parity proof;
- two-start optimization-parity contract;
- real H2/H4 end-to-end production vertical slice;
- CPU candidate census without energy-based selection;
- frozen prospective execution queue;
- append-only outcome and work ledgers;
- per-case singleton, joint, and prefix observed frontiers;
- one terminal decision with allowed and prohibited claims.

## 4. Phase 1 first execution sequence

The fastest safe start is:

1. create a clean worktree from the audited scientific parent;
2. write the protocol digest and source manifest before reading new candidate outcomes;
3. implement the six minimal production components;
4. prove one H2 and one H4 singleton/joint request end to end;
5. run the CPU-only structural census;
6. inspect queue size and freeze the exact execution queue;
7. execute the smallest registered molecular panel in deterministic order;
8. aggregate only after every required item is terminal.

No A100 dependency, ranking model, measurement-cost reconstruction, mechanism study, or new source family may block this sequence.

## 5. Phase 1 terminal branches

| Phase 1 result | Required action |
|---|---|
| No joint-over-singleton structural signal | Stop the method-development claim; write a bounded negative result or archive |
| Signal in only one molecular family or one geometry cluster | Run only a prespecified targeted replication branch |
| Replicated joint advantage but no prefix advantage | Report structural compression, not practical post-growth value; do not start ranking |
| Replicated joint and prefix advantage in at least two molecular families | Authorize Phase 2 structural validation |
| Above condition plus enumeration exceeds the registered practical cap | Phase 2 ranking development may also be authorized |

## 6. Phase 2 is conditional, not a second compulsory campaign

Only one scientifically justified branch is implemented at a time:

- P2-A: targeted replication;
- P2-B: structural/external validation;
- P2-C: ranking development with a generic second-order fairness control.

Optional analyses remain prohibited until the authorized branch reaches its own terminal decision.
