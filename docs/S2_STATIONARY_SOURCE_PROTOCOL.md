# S2 — stationary source protocol

The causal source role is a byte-identical historical development checkpoint
whose parameters are independently stationary at
`||grad_theta E||_infinity <= 1e-8`. The four known development sources are
reconstructed with the pinned exact statevector backend, central finite
differences, three-layer scientific identities, and a full paper-era native
resource recount.

Pool-gradient stopping is a distinct field. These historical checkpoints were
captured at the first paper-era accuracy endpoint before ADAPT reported
`finished`; pool stopping is therefore `null` with an explicit reason and is
not substituted for parameter stationarity. FCI/reference energy is not an
online source-selection input in this study.

S2 freezes identity semantics, not a claim that the historical CEO* growth was
globally converged. All causal comparators must receive the same immutable
source coordinates and structure.
