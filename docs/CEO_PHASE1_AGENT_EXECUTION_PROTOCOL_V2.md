# Phase 1 v2 agent execution protocol

## S0 — successor authority

Verify the immutable v1 A5 No-Go, zero v1 E3 outcomes, A4 census, exact parent
commit, and hashes of all v2 protocols. Stop on any mismatch.

## S1 — outcome-free dominance census and screen design

Reconstruct the strict CNOT dominance rule from A3 and A4. Retain every
eligible singleton. Select the registered joint screen twice and require
byte-identical output. Freeze stratum populations and inclusion probabilities.

## S2 — queue freeze

Reconstruct the Euclidean-projection warm and zero initializations from the B2
source and exact affine maps. Use identity initial inverse Hessians for both.
Generate the 1,266 requests twice, require byte identity and unique IDs, and
verify all work counters remain zero. Do not run an optimizer.

## S3 — runner vertical slice

Implement one request-bound production path. Exercise one H4/synthetic
accepted endpoint, one scientific rejection, cap rejection, injected kernel
failure, artifact failure, exact rollback, crash recovery, and same-request
resume. This stage is calibration only.

## S4 — readiness gate

Require S0–S3 integrity, complete counter reconciliation, clean source and
submodule state, adequate disk, and route qualification. A Go authorizes only
the exact v2 queue.

## S5 — frozen execution

Execute immutable RequestIDs in frozen order. No energy-based reprioritization,
candidate replacement, cap change, or silent retry is allowed. Audit after
every terminal request and push bounded evidence checkpoints.

## S6 — terminal analysis

After 1,266/1,266 terminal rows, reconstruct the complete singleton frontier
and sampled joint screen. Preserve inclusion weights and failure rates. A
positive screen requires held-out confirmation; a negative screen cannot be
promoted to full-universe absence.

## Mandatory stop conditions

Stop fail-closed on identity mismatch, counter mismatch, non-atomic artifact,
unregistered request, cap uncertainty, rollback mismatch, source mutation,
route parity failure, or insufficient storage. Never repair a scientific
failure by changing the frozen population or endpoint.
