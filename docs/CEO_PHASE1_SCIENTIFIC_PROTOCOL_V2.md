# CEO post-growth compression — Phase 1 scientific protocol v2

## Status and authority

This is an additive successor to Phase 1 v1. It does not modify the v1
artifacts or reinterpret the v1 A5 decision. The v1 exhaustive design ended at
`NO_GO_A5_E2_OR_QUEUE_INVALID` because 88,148 targets and 176,296 optimizer
starts exceeded demonstrated capacity before any E3 outcome was observed.

## Scientific question

Can a preregistered joint CEO transformation produce an accuracy-feasible
canonical-CNOT point that is not reached by the complete eligible singleton
language for the same B2 source?

V2 is a screening experiment. It is not an exhaustive joint-frontier study.

## Exact outcome-free dominance reduction

A K=2 target is the direct sum of two disjoint exact atomic restrictions. Its
variational manifold is therefore a subset of the manifold obtained by
applying either constituent singleton alone. A joint target can improve the
primary CNOT frontier only if

\[
C_{ij}<\min(C_i,C_j).
\]

Targets failing this inequality are removed before any candidate energy. This
is a mathematical/resource dominance rule, not a predictor of energy.

All singleton targets with a strict CNOT reduction are retained. Consequently
the singleton comparator is complete for the registered primary endpoint.

## Prospective joint screen

The remaining joints are stratified within each case by:

1. unordered constituent transformation-kind pair; and
2. exact canonical-CNOT saving from B2.

LiH 3.0 A is exhaustively retained because its eligible joint universe has only
60 members and is already a historical development case. In H6 1.5 A, H6
3.0 A, and BeH2 3.0 A, the two lowest SHA-256 ranks per nonempty stratum are
selected using the fixed seed
`phase1-v2-prospective-stratified-joint-screen-v1`.

Selection uses no candidate energy, optimizer result, FCI value, historical
winner label, Hessian score, or parameter magnitude. Population count, sample
count, and inclusion probability are recorded for every selected joint.

## Optimization and acceptance

Each frozen target has exactly two starts: the Euclidean least-squares
projection of the B2 coordinates into the exact affine target manifold, and
zero target coordinates. Both starts use the identity matrix as the initial
inverse Hessian. This deliberately removes recycled-Hessian quality as a
target-dependent confounder. Both paid starts remain in work accounting. An endpoint requires
the pinned BFGS success condition, finite values, independent energy/state and
analytic-gradient agreement, gradient infinity norm at most `1e-8`, exact
constraint satisfaction, and repeated physical-resource recount.

Accuracy feasibility is

\[
E_{\mathrm{target}}-E_{B2}\le 10^{-4}\;E_h.
\]

The better valid start is the target result. The primary comparison minimizes
canonical logical CNOT count subject to this accuracy guard. Depth and
parameter count are secondary descriptive endpoints.

## Interpretation boundaries

A positive sampled joint point is a screening signal requiring held-out
confirmation. A negative screen means only that no signal occurred in the
frozen sample. It is not evidence that the full 34,245-member dominance-eligible
joint universe contains no improvement.

No Measurement Cost, noise, routed hardware, universal CEO, V5 superiority,
or population-wide prevalence claim is authorized in Phase 1 v2.
